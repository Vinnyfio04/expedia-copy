# Write the Part 1 report

Purpose: Produce the required Markdown report from verified repository and
browser evidence without inventing missing artifacts.

## Prompt

```text
Read AGENTS.md, README.md, docs/assignment_instructions.md, the current source,
tests, and Git history. Create the expedia-copy Part 1 report in the requested
location using exactly one level-one heading and these level-two sections:
Repository and commit, Implementation, Verification, and Project context and
next steps.

Include the GitHub repository and exact submitted commit. Explain the frontend,
FastAPI, and plain Python responsibilities and their JSON boundary. Record each
manual browser check as an action, expected result, and observed result. Include
successful hotel-name and no-results searches plus automated check outcomes.
Link only screenshots and context files that actually exist and are accessible
in the repository; identify missing evidence explicitly.

Link README.md, AGENTS.md, the design note, selected prompts, and current handoff
when they exist. State current limitations and the next task. Do not claim that
unrun checks passed, and do not change application code or dependencies.
```
